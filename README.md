# 💱 Conversor de Moedas

Conversor de Moedas com HTML, CSS e JavaScript.
Converte Real para Dólar, Euro, Libra e Bitcoin.

## 🚀 Como usar

1. Digite o valor em Real
2. Escolha a moeda
3. Clique em Converter

## 🛠️ Tecnologias

- HTML
- CSS
- JavaScript
